# Continuous analysis with the Flexo Change Adapter

This repository provides a simple, shareable way to open the presentation slides
for the SysML v2 grokking research workflow. The goal is to let collaborators
and talk attendees view the story from a public link, without needing the
research workspace or its local development setup.

## Open the slides

**[View the presentation](https://dynamicalsystemsgroup.github.io/openmbee-grokking-talk/)**

The same page is in [`index.html`](index.html). It is a portable, self-contained
presentation: diagrams, selected source and evidence views, and the speaker
guide are embedded in the page. You can also download `index.html` and open it
locally in a browser.

GitHub Pages publishes the root of the `main` branch. This repository is a
sharing and presentation entry point; the linked research projects remain the
source for their code and ongoing work.
